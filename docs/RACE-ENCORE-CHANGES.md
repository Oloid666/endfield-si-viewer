# 結算活起來、隨機性與小聰明重修

## 已實作

- 遊戲首頁第一個直接進入「莊芳宜 · 失控辦公椅」，不加測試標籤。甩蔥、爬塔、竹筏依序在下方標「測試開發中」。坐騎頁仍能切祀毛筆。
- 對話頭像移在字幕左上，直式 112px、驚恐／生氣 132px，橫式 88px。人物圖集裁切放大，小聰明模型與五態圖集同步重修。
- 依官方祀敘事影片約 3:05 重建小聰明：連續黑色罩袍輪廓、圓頂、窄曲面紙臉、黑色額頂、寬袖／短指與較低調的紙纖維，減少便利貼與黑球感。
- 成績卡縮至上方，設定、操作說明與來源收在可展開項目。比賽結束後停車同框，只有視覺與短劇時鐘繼續，成績／碰撞／勝負不變。
- 15 組原創短劇素材，按角色、勝負、撞擊及跳板表現篩選，一段兩到四人句、逐句換頭像。最近三組避重複，播完安靜五至七秒。四人劇只在對手實際參賽時出現；單人不額外下載祀。
- 結算眨眼、點頭、整理袖口、指向對手、揮手，跟班擺手／躲到椅後／累癱。比賽中不定時回看、眨眼與擺手，僅影響表演。
- AI 每局選前段搶跑或留墨後追，前後半段速度只作小幅對稱變化，收筆冷卻不同，保留 0.75 秒可見預兆。無瞬移、橡皮筋追趕、隨機反轉方向或抽獎決定勝負。
