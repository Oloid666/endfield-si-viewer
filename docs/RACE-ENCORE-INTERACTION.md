# 結算點角色、自己滾與接話

## 本輪完成

- 結算可直接點畫面上的莊芳宜、祀、龍泡泡或小聰明；只開放實際在場角色。只點一下觸發，拖曳、長按、取消及第二指操作不視為點擊。
- 莊芳宜會轉椅、晃椅；祀會轉身、晃毛筆並揮手；跟班會繞腹部翻一整圈、彈跳與壓扁回彈。動作有界，不會越滾越遠。
- 不點也會輪流自己動，每次間隔約 3.3–4.5 秒，沿用既有結算與渲染循環。
- 點擊立刻有動作，回嘴排在正在播放的短劇後面，不中斷句子。最多保留兩個不同角色的點擊回嘴，接完再恢復持續拌嘴。
- 「賽事設定與操作」內提供同樣的角色互動按鈕，支援鍵盤操作；平常收合，主畫面只多一行點擊提示。
- 重玩、離場清除動作與回嘴。比賽引擎、用時、勝負、碰撞數保持凍結；沒有新增模型下載、計時器、Renderer、依賴或後處理。

`EncorePlay` 管純視覺動作時鐘；`RaceEncore` 排回嘴；`RideStage` 表演及投影點選區域；`RideGame` 處理觸控與生命週期。
