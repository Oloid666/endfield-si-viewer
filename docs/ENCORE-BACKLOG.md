## 2026-10-22：贏家登場與鏡頭順序（已實作，待手機真機驗收）

1. 依實際勝負讓贏的人笑，或出現明顯的開心特效。
2. 剛進結算時先把鏡頭拉近贏家，讓觀眾看清楚誰贏了。
3. 等這輪結算開場該說的台詞完整說完，再平順縮回同框；以對話播放完成為準，不硬切固定秒數。
4. 有四人參賽時回到四人同框；單人模式保留實際在場角色。
5. 拉回後持續拌嘴，保留點角色的動作與回嘴、閒置自行活動。

已加入勝者開場台詞、八顆星星的開心特效、兩套實際骨架的微笑，以及依完整台詞播放時長進行的特寫／退鏡頭。點擊互動、閒置活動與持續拌嘴保留。

## 結算祀被遮擋、人物朝向與站位（已實作，待手機真機驗收）

- 使用者手機截圖中，祀的頭臉與上半身被上方結算卡遮住，只看得到側坐的腿部與毛筆。
- 結算同框時讓祀面對畫面，頭臉與上半身轉向觀眾，避免一直側身。
- 調整祀與毛筆的站位／構圖，讓祀在畫面中下移，露出頭臉及身體，使人物更明顯；不要只降低模型世界高度而讓人物沉入地面。
- 避開結算卡、下方對話頭像與字幕；手機直式優先，橫式亦須檢查。待機、點擊動作與贏家特寫拉回後都需維持可見。
- 使用者後續指示執行，本輪已修正：縮短結算卡、額外資料收進設定、依實際 UI 留白取景，祀面向觀眾並前移毛筆站位。橫直式與完整結算互動會一併驗證。
