# 坐騎試作美術參考

本次重畫使用程序幾何、Canvas 面部筆觸與原創材質。以下圖片僅作外型研究，未放入網站、未下載或重新散布相應的官方／第三方 3D 模型。原有祀、莊方宜人物仍是使用者提供的 GLB，來源與 CC BY 4.0 保留在既有模型資料及遊戲說明中。

- **小聰明**：終末地官方新版祀影片中的黑色圓頭、紙面綠色眉眼、短手腳與墨尾。參考 [官方影片頁](https://endfield.hypergryph.com/video) 及本站開發時查閱的官方角色影片約 3:05 影格。重畫重點為頭大身短、紙面在圓頭下方、閉眼筆觸；噴射或碰撞時切換另畫的慌張筆觸。
- **龍泡泡**：[Neyko 的外型展示圖](https://booth.pm/ja/items/7933749)。只看展示圖，未下載模型。使用白色圓身、金色上彎角、半瞇綠黃眼、眉點、ω 嘴、小腳、紅繩及小吊牌等辨識元素，移除舊試作的大綠色面罩與黑點眼。
- **迷你帝江號**：以 [終末地官方「Voyage to the Stars」活動頁](https://endfield.gryphline.com/activity/voyage-to-the-stars/en-us/) 的 [星艦結構概念圖](https://web-static.hg-cdn.com/endfield/activity/voyage-to-the-stars/assets/imgs/ship_1_p.b2144a.webp) 作環架、桁架、模組艙與縱向主樑的結構參考，另參照帝江號的軌道總部設定。本站是適合乘坐的 Q 版二創改裝，並非精確官方資產複刻；增加核心、座椅、噴口及 O.M.V. DIJIANG 字樣方便辨識。
