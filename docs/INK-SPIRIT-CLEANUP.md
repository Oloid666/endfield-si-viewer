# 小聰明、人物頭像與持續拌嘴修正

本輪完成討論清單第 1–12 項。

- 小聰明改為大圓頭、短罩袍與曲面白臉；白臉及六種五官狀態直接畫在圓頭 UV，使用受光材質。沒有紙牌、背板、紙纖維或臉片獨立翹動。
- 寬袖改用有厚度的彎曲輪廓，末端短指；腳縮小，尾巴為單片收尖墨痕。每邊袖口按材質合併，受驚時整體輕微壓扁與扭動；追逐鏡頭下轉動整顆頭，讓臉能被看見。
- 祀與莊的五態頭像由原 GLB 骨架重新渲染；眉眼、嘴角與頭部微調依人物分別設定。移除原本臉上的粗黑線、漫畫白眼、叉眼和灰色方塊。情緒符號只在臉旁。
- 20 格圖集升為每格 384×384，用 WebP 保持約 319 KiB，略小於舊 PNG。版本網址避免舊快取。
- 結算持續輪播 19 組短劇，依勝負／碰撞／跳板與在場角色篩選，最近三組避重複。段落之間只停 0.6–1 秒，保留上一句直到下一段；不會播完幾段就停，也不再長時間隱藏字幕。
- 結算停頓時角色保留待機；說話時頭像及動作同步。重玩或離開停止這個結算生命週期，下一局重設。

`InkCompanion.js` 僅管理小聰明幾何與貼圖；`RideProps` 提供共用介面與動畫；離線 `tools/render-race-portraits.mjs` 產生靜態圖集。網站仍只使用既有 Renderer／主循環，沒有安裝新依賴，也沒有修改使用者提供的 GLB。
