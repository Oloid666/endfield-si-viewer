# 展示陪伴、四人頭像與跳板改版

本輪依討論執行：

1. 莊芳宜展示區：獨立已驗證骨架設定，眨眼、呼吸、整理袖口、看龍泡泡；程序龍泡泡在身旁飄動、擺手、搖尾。與賽車拖繩角色分開，切換遊戲時隱藏，返回還原，可暫停待機。
2. 小聰明：小身體、短手腳、曲面厚紙面、較清楚的綠色眉眼與不規則墨尾。主控祀及 AI 祀都綁在毛筆後方。
3. 對話頭像：四位角色各五態，共二十格；祀與莊取自原 GLB 的本站渲染並疊加漫畫眉眼，跟班取自本站程序模型。圖集靜態切換，一次一位說話者；多人句拆開輪流播。廣播與系統提示不冒用角色頭像。
4. 祀參賽故事：本來只想參賽領免費墨水，聽到管理員親自頒獎就認真了。主控祀有開場，AI 祀在莊線亦會提起墨水。兩隻跟班在結算接話。
5. 莊的比賽表演：開場抱手、公告抬頭、接管前傾、施法抬手；龍泡泡待機飄動、轉向擺手、起飛等待時搖頭。
6. 跳板過坑：兩條坐騎路線各一處。黃色跳板配箭頭與前方標牌，自動起跳；速度、對準與落地橫向位置決定是否通過。跟班晚半拍彈射。失誤只扣速、斷噴射並救回，不重開整局。
7. AI 加速預兆：收筆前約 0.75 秒抬手、墨環發亮，HUD 顯示「蓄墨」，再進入噴射。
8. 跟班記仇：累積撞擊會改變紙面／眼神和說話頭像，三次觸發記仇吐槽，平穩駕駛後逐步消氣；暫停不推進，重玩清除。
9. 差距對話：終點前依實際領先／落後／並排觸發不同台詞，同一狀態不逐幀重複，跳板與重要差距提示優先於一般撞擊吐槽。

轉盤、隨機加減速、甩圈補給、雙人機關門保留為討論候選。本輪保持原有按鈕，不新增付費服務、連線或依賴。
